@AGENTS.md

이 프로젝트는 Ping이라고 하는 위치 기반 SNS야. 사용자가 이미지를 업로드하면 해당 이미지에 포함된 메타 데이터 기반 혹은 임의로 지정한 위치를 피드에 포함하여 내 주변 정보를 공유하고 확인할 수 있는 형태야.
일단 인스타그램을 벤치마킹하려고 해

이미 백엔드는 구현이 끝났고 이 것에 맞춰서 프론트엔드 페이지를 구성해 주면 되
다음은 API 문서야

feed page는 지정하는 하나의 피드를 가져와서 보여주는 페이지
chat은 로그인된 사용자가 속한 채팅방을 보여주는 페이지
chat에 cid 채팅방 아이디가 주어지면 채팅방 속 메시지를 보여주고 메시지를 보낼 수 있는 페이지
user join 페이지는 회원가입 페이지
user profile은 제공된 uid의 user의 프로파일과 피드를 보여주는 페이지
main 페이지는 로그인한 경우 지도에 현재 위치 주변의 피드를 보여주는 페이지
